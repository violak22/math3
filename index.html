Системы случайных величин и корреляция

Системы случайных величин

Система случайных величин (ССВ)
\[ F(x,y) = P(X < x, Y < y) \]
Смысл: Вероятность попадания случайной точки в левый нижний квадрат с вершиной в точке (x,y).
Плотность: \(f(x,y) = \frac{\partial^2 F}{\partial x \partial y}\).
Свойства F(x,y):
1) \(0 \le F(x,y) \le 1\)
2) Неубывающая по каждому аргументу
3) \(F(-\infty, y) = F(x, -\infty) = F(-\infty, -\infty) = 0\)
4) \(F(x, +\infty) = F_1(x)\), \(F(+\infty, y) = F_2(y)\)
5) \(F(+\infty, +\infty) = 1\)

Свойства f(x,y):
1) \(f(x,y) \ge 0\)
2) \(\iint_D f(x,y) dx dy = P((X,Y) \in D)\)
3) \(F(x,y) = \int_{-\infty}^x \int_{-\infty}^y f(x,y) dx dy\)
4) \(\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x,y) dx dy = 1\) (объем)

Вероятность попадания в прямоугольник:
\(P(a \le X < b, c \le Y < d) = F(b,d) - F(a,d) - F(b,c) + F(a,c)\)

Зависимые и независимые СВ

Независимые СВ
Свойства из конспекта:
Если X и Y независимы, то корреляционный момент \(K_{xy} = 0\) и коэффициент корреляции \(r_{xy} = 0\).
Обратное неверно (из нулевой корреляции не следует независимость).

Теорема умножения вероятностей:
Для независимых событий: \(P(AB) = P(A) \cdot P(B)\).
Для независимых СВ: плотность совместного распределения равна произведению плотностей \(f(x,y) = f_1(x)f_2(y)\).

Моменты распределения ССВ

Начальный момент Центральный момент
\[ a_{ks} = M(X^k \cdot Y^s) \]
Начальные моменты 1-го порядка: \(a_{10} = M(X) = m_x\), \(a_{01} = m_y\).
\[ \mu_{ks} = M((X - m_x)^k \cdot (Y - m_y)^s) \]
Центральные моменты: \(\mu_{20} = Dx\), \(\mu_{02} = Dy\).
Корреляционный момент
\[ K_{xy} = \mu_{11} = M(XY) - m_x m_y \]
Свойства \(K_{xy}\):
1) Характеризует степень зависимости случайных величин.
2) Если величины независимы, то \(K_{xy} = 0\) (обратно неверно).

Недостатки \(K_{xy}\):
1) Численное значение зависит от единиц измерения величин.
2) \(K_{xy} \to 0\) за счет массового отклонения значений одной из СВ от её мат. ожидания.

Коэффициент корреляции

Коэффициент корреляции
\[ r_{xy} = \frac{K_{xy}}{\sigma_x \cdot \sigma_y} \]
Свойства (из конспекта):
1) Характеризует степень зависимости. Если независимы, то \(r_{xy} = 0\) (обратное неверно).
2) Изменяется от -1 до 1: \(-1 \le r_{xy} \le 1\).
3) \(r_{xy} > 0\) — прямая линейная корреляция.
4) \(r_{xy} < 0\) — обратная отрицательная корреляция.
\(r_{xy}\) Степень зависимости
\(0 < |r_{xy}| \le 0.3\)практически отсутствует
\(0.3 < |r_{xy}| \le 0.5\)слабая
\(0.5 < |r_{xy}| \le 0.7\)умеренная
\(0.7 < |r_{xy}| < 1\)сильная
\(|r_{xy}| = \pm 1\)функциональная
Предельные теоремы и регрессия

Правило трёх сигм

Правило трёх сигм
\[ P(|X - a| \le 3\sigma) \approx 0.9973 \]
Смысл: Практически все значения нормально распределенной СВ лежат в интервале \((a - 3\sigma, a + 3\sigma)\).
Вероятность отклонения: \(P(|X - a| > 3\sigma) \le 0.0027\).

Функция и уравнение регрессии

Функция регрессии
\[ M(Y|X=x) = \varphi(x) \]
Смысл: Показывает среднее значение \(Y\) при фиксированном \(X=x\).
Линейная регрессия: \(M(Y|X=x) = a_0 + a_1 x\).
Уравнение регрессии — это формула, задающая функцию регрессии.

ЦПТ и неравенство Чебышева

Неравенство Чебышева
\[ P(|X - m_x| \ge \varepsilon) \le \frac{D_x}{\varepsilon^2} \]
Центральная предельная теорема
\[ \sum_{i=1}^n X_i \xrightarrow{d} \mathcal{N}(n\mu, n\sigma^2) \]

Теоремы Чебышева и Бернулли

Теорема Чебышева
\[ P\left(\left|\frac{1}{n}\sum X_i - \frac{1}{n}\sum M(X_i)\right| < \varepsilon\right) \ge 1 - \frac{D}{n\varepsilon^2} \]
Теорема Бернулли
\[ P\left(\left|\frac{m}{n} - p\right| < \varepsilon\right) \ge 1 - \frac{pq}{n\varepsilon^2} \]

ЗБЧ и теоремы Муавра-Лапласа

Закон больших чисел
Формы ЗБЧ: Теорема Чебышева (общий случай) и Теорема Бернулли (частный случай).
Локальная теорема Муавра-Лапласа
\[ P_n(m) \approx \frac{1}{\sqrt{npq}} \varphi\left(\frac{m - np}{\sqrt{npq}}\right) \]
Интегральная теорема Муавра-Лапласа
\[ P_n(m_1 \le m \le m_2) \approx \Phi(x_2) - \Phi(x_1) \]
Обозначения: \(x = \frac{m - np}{\sqrt{npq}}\), \(\Phi(x) = \frac{1}{\sqrt{2\pi}} \int_0^x e^{-t^2/2} dt\).
